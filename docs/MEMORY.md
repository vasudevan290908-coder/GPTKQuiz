# Project Memory & Context

## 1. Project Context
* This document maintains the ongoing record of decisions, preferences, and progress for the web project.

## 2. Agreed Tech Stack
* Frontend: HTML, CSS, React, TypeScript, JavaScript.
* Component Architecture: Primary use of JSX/TSX for building pages as modular, separate, reusable components using tags.
* Backend: Python, Java.
* Database: MySQL.
* Typography: Apple SF Pro.
* Icons & Logo: SVG only.
* Video: MP4 only.
* Formats: JSON, Markdown.

## 3. Communication Constraints
* No code snippets in chat discussions. Explanations and documentation must remain conceptual, clear, and direct.
