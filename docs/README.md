# Web Project Documentation

Welcome to the project repository. This project is structured around clear specifications, modern frontend and backend technologies, and consistent design rules.

## Project Documents
* **ARCHITECTURE.md:** High-level system structure, layers, and service communications.
* **DESIGN.md:** Design system, typography, vector assets, and styling rules.
* **MEMORY.md:** Project history, recorded preferences, and context tracking.
* **PHASES.md:** Step-by-step roadmap from requirements to deployment.
* **PRD.md:** Product requirements, target audience, and feature definitions.
* **RULES.md:** Project-wide constraints, media standards, and development guidelines.

## Technology Stack Summary
* **Frontend:** React, TypeScript, HTML, CSS, JavaScript
* **Authentication:** Firebase Auth (1-click Gmail & Email authentication)
* **Realtime Sync:** Firebase Realtime Database (Live screen updates when lecturer edits)
* **Backend & DB:** Python, Java, MySQL
* **Typography:** Apple SF Pro
* **Assets:** SVG (icons & logo), MP4 (video)
* **Formats:** JSON, Markdown

## 100% Free Hosting via GitHub Pages (No Paid Domain, No Personal PC Needed)
Since the webpage is fully self-contained with CDN assets, it can be hosted permanently online for free:

1. **Log in to GitHub:** Open github.com in any web browser.
2. **Create New Repository:**
   * Click "New" repository.
   * Name it (for example: `university-portal`).
   * Set visibility to **Public**.
3. **Upload Files:**
   * Click "Upload files" on GitHub.
   * Drag and drop the files from `D:\web-project\` (especially `index.html` at the root, and the `src`, `docs`, `assets` folders).
   * Commit the upload to `main`.
4. **Turn On Free Hosting:**
   * In your GitHub repository, go to **Settings** -> **Pages** (in the left menu).
   * Under **Branch**, select `main` and root `/`, then click **Save**.
5. **Live URL:**
   * GitHub will automatically generate a free live website link: `https://<your-github-username>.github.io/<repository-name>/`
   * You can open this link from any computer or mobile phone anywhere in the world at zero cost!
