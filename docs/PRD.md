# Product Requirements Document (PRD)

## 1. Product Overview
* A modern, high-performance web platform built with a React TypeScript interface, backed by Python and Java services, and backed by a MySQL database.

## 2. Target Audience
* Users looking for an intuitive, fast, and accessible digital experience across desktop, tablet, and mobile devices.

## 3. Key Functional Requirements
* **Authentication Engine (Firebase Auth):** 1-click Google/Gmail and email/roll authentication for students and lecturers with automated session token verification.
* **Dual-State Animated Portal:** Smooth transition between Login Mode (Student Sign In & Teacher Portal) and Registration Mode (Welcome Back & Create Account) with fluid micro-motion.
* **Live Screen Synchronization (Firebase Realtime DB):** Instant, live screen updates across student devices whenever a lecturer makes updates or edits coursework.
* **Responsive User Interface:** Seamless presentation and fluid navigation across all screen viewports in dark Neo-Brutalist design.
* **Vector Visual Identity:** Crisp visual assets, using SVG exclusively for icons and branding.
* **Data Reliability:** Hybrid persistence using Firebase Realtime DB for live state, supported by MySQL for structured academic records.

## 4. Non-Functional Requirements
* Fast load times and optimized rendering performance.
* Accessibility standards compliance for contrast, legibility, and usability.
* Data integrity and secure storage of all records.
